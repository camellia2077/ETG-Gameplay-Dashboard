## [v0.4.4] - 2026-08-07

### 技术改进/重构 (Changed/Refactor)

* 为代码行数扫描器(loc scanner)明确重构辅助边界：
  * 扫描器只报告代码行数、目录文件数量、扫描范围和阈值结果，不执行静态语义分析，也不直接决定文件的保留、移动、拆分或合并。
  * 新增 Agent 主导的重构工作流和 [Refactoring Guidelines](../../architecture/refactoring-guidelines.md)，明确以降低职责耦合、提升内聚性和可维护性为目标。
  * 补充模块化单体架构边界，区分 UI、应用流程、Core 领域逻辑以及 Runtime/Infrastructure 适配层。
* 重构控制面板(Control Panel)的职责边界：
  * 将面板生命周期和 GUI 焦点释放集中到 `CommandPanelLifecycleCoordinator`。
  * 将控制器方向导航集中到 `ControllerFocusNavigator`。
  * 将地图 Reveal Map 和楼层作用域状态集中到 `MapFeatureRuntimeCoordinator`。
  * 将拾取物(Pickups)目录查询、别名、排序、搜索和过滤集中到 `PickupBrowserQueryService`，并抽取 `PickupBrowserEntry`、`PickupBrowserFilters` 和图标数据模型。
  * 将 Loadout 编辑器缓存刷新集中到 `LoadoutEditorDataCoordinator`，将编辑过程状态集中到 `LoadoutEditorState`。
* 重构房间敌人回溯(Room Enemy Rewind)运行时模块：
  * 从 `RoomEnemyReplayService` 中抽取 `RoomRewindCleanupService`、`BossRoomDecorationRestorer`、`RoomPlayerStateRestorer`、`RoomEnemyWaveSpawner`、`RoomReplayWaveDiagnostics` 和共享回溯状态模型。
  * 保留原有的房间进入、增援波次记录、敌人生成、Boss 奖励重置、装饰物恢复和玩家状态恢复流程。
  * 更新架构与日志文档，明确玩家快照只在玩家回溯开启时捕获。
* 将玩家回溯配置从 `BossPlayerRewindEnabled` 统一为 `PlayerRewindEnabled`，默认值改为开启，同时继续由玩家在 Room 页面中持久化控制。

### 修复 (Fixed)

* 修复拾取物(Pickups)、Boss Rush 以及其他次级页面首次使用鼠标左键点击 Back 时错误关闭整个控制面板(Control Panel)的问题：
  * 统一次级页面 Back 按钮的位置和绘制入口。
  * 避免 Back 按钮与右上角全局关闭按钮的点击区域重叠。
  * 保留各页面原有的返回目标，例如 Pickups 返回 Control Panel，Loadout 子页面返回对应的上级页面。
* 修复房间回溯后玩家血量、护甲、空响弹、武器弹药及其他玩家状态无法恢复的问题，统一接入玩家状态快照恢复流程。
* 修复 Rewind 关闭时 Room 页面仍可操作刷新模式、Player Rewind、Rewind Cleanup 和 Spawn 按钮的问题：
  * 相关控件使用统一禁用主题颜色。
  * 鼠标和控制器确认操作均被阻止。
* 修复 Player → Combat 页面中 Keyboard Aim Assist 关闭时倍率控件仍显示为可用的问题：
  * Aim Assist 为 `Off` 时倍率选择使用禁用状态主题。
  * 鼠标、控制器和快捷执行均不会在关闭状态下修改倍率。
