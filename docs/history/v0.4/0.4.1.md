## [v0.4.1] - 2026-07-28

### 新增功能 (Added)

* 新增 `BossRushCoroutineHost` 独立宿主组件，基于原生 `MonoBehaviour` 托管 Boss Rush 模式(Boss Rush)的全局协程流程。

### 技术改进/重构 (Changed/Refactor)

* 优化控制台面板(command panel)开启性能，在后台静默预热标题文字字体渲染（进入场景 3 秒后执行屏幕外绘制，且在语言切换后重置预热），将面板首次打开耗时从约 `694 ms` 降低至约 `158 ms`（标题绘制耗时由约 `643 ms` 降至约 `0.43 ms`）。
* 优化 `Start Items` 初始物品预设界面的图标加载机制，将预设预览图标 `PickupIcon` 的生成由单帧同步加载重构为分帧队列增量处理（每帧仅生成 1 个未缓存图标，未完成时显示占位符），解决首次打开预设卡片区域约 `190 ms` 的绘制卡顿。
* 扩展控制台面板(command panel)端到端耗时与 `LoadoutPage` 页面绘制性能追踪日志，支持细分控件绘制与可见项渲染的毫秒级调试。
* 在 Boss Rush 模式(Boss Rush)激活期间暂时禁用房间回溯(Rewind)，拦截面板 Rewind 按钮及 `C` 快捷键(hotkey)触发并显示提示，避免在 Boss Rush 下使用回溯导致无法进入下一层及无法使用 Esc 菜单(Esc menu)的问题。
* 重构 Boss Rush 协程调度，使用插件自身的 `BossRushCoroutineHost` 替换 `ETGMod.StartGlobalCoroutine` 与 `ETGMod.StopGlobalCoroutine`，不再依赖外部 API 协程服务。
* 重构锁定弹药功能，使用原生 `LockedAmmoComponent` (继承 `MonoBehaviour` 并通过 `Update()` 维护) 替代依赖 `ModTheGungeonAPI` 的 `GunBehaviour` 事件回调机制。
* 更新部署与发布工具 `tools/tool_common.py`、`tools/deploy/clean_mod.py` 和 `tools/release/release_package_builder.py`，发布包(release package)仅包含插件自身及必要依赖（如 `0Harmony.dll` 和 `Newtonsoft.Json.dll`），不再分发、安装或清理 `ModTheGungeonAPI` 文件。
* 同步更新项目相关文档、关于说明与依赖列表，移除对 `ModTheGungeonAPI` 的运行时依赖要求。
* 重命名插件 GUID 为 `etg-gameplay-dashboard`，主配置文件重命名为 `etg-gameplay-dashboard.cfg`。
* 统一迁移默认配置文件与本地化文件命名前缀为 `EtgGameplayDashboard.*`（如 `EtgGameplayDashboard.rules.json5`、`EtgGameplayDashboard.aliases.json5` 及语言包文件）。

### 弃用/删除 (Deprecated/Removed)

* 彻底删除对 `ModTheGungeonAPI` (`etgmodding.etg.mtgapi`) 的运行与项目依赖，包括 `Plugin.cs` 中的 `[BepInDependency]` 声明以及 `EtgGameplayDashboard.csproj` 中的程序集引用。
* 删除带有旧前缀 `ETG-Gameplay-Dashboard.*` 与 `randomgun.etg-gameplay-dashboard.cfg` 的默认配置文件。
