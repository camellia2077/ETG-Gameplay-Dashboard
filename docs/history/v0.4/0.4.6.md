## [v0.4.6] - 2026-08-07

### 技术改进/重构 (Changed/Refactor)
* 将 `src/EtgGameplayDashboard.Core/EtgGameplayDashboard.Core.csproj`、`src/EtgGameplayDashboard/EtgGameplayDashboard.csproj` 和 `tests/EtgGameplayDashboard.Core.Tests/EtgGameplayDashboard.Core.Tests.csproj` 从旧式 MSBuild 项目迁移为 SDK-style 项目，保留 `net35` 目标框架。
* 统一构建和测试脚本使用 `dotnet build`，移除对固定 MSBuild 4.8 安装路径的依赖，并补充现代 .NET 工具链配置文档。
* 新增根目录 `.editorconfig` 和 `Directory.Build.props`，统一 C# 代码风格并启用 Roslyn .NET 分析器。
* 为 `dotnet format analyzers` 增加 JSON 报告拆分工具 `tools/devtools/split_analyzer_report.py`，按代码文件生成可解析的静态分析任务清单。
* 重构 `EtgLoadoutConfigResolver` 为静态解析器，使用具体的 `UtcTickSeedProvider` 类型，并将窗口标题读取改为原生字符缓冲区 P/Invoke。
* 统一诊断、日志和导出数据中的数值格式化与字符串比较，使用 `InvariantCulture` 和 `StringComparison.Ordinal`，并复用重复的静态数组配置。

### 修复 (Fixed)
* 修复 Win32 窗口 API 返回值未检查的问题，避免窗口句柄或窗口标题读取失败时继续使用无效结果。
* 修复静态分析器发现的区域设置相关格式化问题，确保日志、JSON 和诊断输出不受系统区域设置影响。
* 修复旧式分析器自动修复可能生成重复静态字段的问题，确保构建和测试保持稳定。
