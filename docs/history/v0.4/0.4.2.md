## [v0.4.2] - 2026-08-01

### 新增功能 (Added)

* 在 `Player -> Combat` 分类中新增“主动道具冷却” (`Active Cooldown`) 开关：
  * 开启后持续清除当前玩家持有的所有主动道具冷却状态，包括房间冷却、时间冷却和伤害冷却（基于 ETG 原生 `PlayerItem.ClearCooldowns()` 实现）。
  * 开关状态支持配置持久化。
  * 补充中英文 UI 文本（中文：`主动道具冷却`，英文：`Active Cooldown`）。
  * 支持手柄 UI 导航焦点，并在插件退出清理时恢复运行时状态。

### 修复 (Fixed)

* 修复插件退出清理（Teardown）阶段的生命周期问题：
  * `PlayerStatMultiplierService` 在插件销毁时不再调用 `PlayerStats.RecalculateStats()`。
  * `RoomEnemyReplayService` 在插件销毁时不再读取 `GameManager.CurrentFloor`、Dungeon 或 Minimap。
  * 消除游戏退出阶段触发的 `SteamAPI twice in one session` 与项目相关的 `NullReferenceException` 空引用异常。
  * 保持正常运行期间的属性倍率、房间敌人回放及地图诊断行为不变。
* 修复 Pickup catalog 导出阶段对 `SPECIAL` / `EXCLUDED` 品质调用 ETG `GetBasePrice` 产生错误日志的问题：
  * 普通品质继续读取 `pickup.PurchasePrice`，使用自定义价格的条目读取 `pickup.CustomCost`。
  * `SPECIAL` / `EXCLUDED` 特殊品质条目的导出价格记录为 `0`，避免调用不支持这些品质的普通价格计算函数，消除启动导出阶段的 `Invalid quality : SPECIAL/EXCLUDED in GetBasePrice` 日志。
  * 特殊品质条目完整保留在 catalog 中，不影响目录内容。
* 修复输入系统尚未初始化时访问 `BraveInput` 导致的高频 Error 及空引用异常：
  * 在读取玩家输入实例前先调用 `BraveInput.HasInstanceForPlayer()` 进行存在性检查。
  * 输入实例不存在时直接返回空值，避免调用会主动打印 Error 日志的 `GetInstanceForPlayer()`。
  * 覆盖控制台面板光标渲染 (`CommandPanelCursorRenderHooks`)、控制器瞄准锁定 (`ControllerAimLockHooks` & `ControllerAimLockService`) 等输入路径。
  * 消除了启动期 `Player 0/1 is attempting to get a BraveInput instance` 错误日志，且不影响初始化完成后的键盘、鼠标和手柄行为。
* 修复初始物品预设 (`Start Items Preset`) 查看与编辑流程：
  * 修复点击 `Open Preset` 会自动切换当前生效预设 (`StartItems.ActivePreset`) 的问题。
  * 现在点击 `Open Preset` 仅打开并编辑目标 preset，仅当点击 `Select` 才会切换实际生效的预设。
  * 增加独立的编辑 preset 上下文，确保打开非当前 preset 后，详情页精确显示与编辑所打开的 preset。

### 技术改进/重构 (Changed/Refactor)

* 重构全开地图 (`Reveal Map`) 与楼层传送行为：
  * 将 `Reveal Map` 改为当前楼层的临时状态：当前楼层点击后保持按钮开启状态；成功传送楼层后关闭 Control Panel 并清理地图全开状态；检测到进入下一层后自动关闭按钮开启状态。
  * 不写入配置文件，不做持久化，传送到新楼层不会自动强行执行全开地图。
  * 修复其他操作（如增加最大生命值等）错误触发地图全开按钮状态的问题。
  * 同步更新地图传送相关说明文档。
